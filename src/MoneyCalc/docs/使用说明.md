# 财务小算盘 · 使用说明

> 左边选计算器，右边填数字，**没有「计算」按钮**——输完就出结果。
> 版本 0.1.1。全中文，不联网，不开文件。

---

| 操作 | 效果 |

## 一、人民币大写

填一个金额，下面立刻显示大写。

- 支持千分位逗号：`1,234,567.89`
- 支持负数：`-1200.5` → 负壹仟贰佰元伍角
- 上限 `999,999,999,999.99`，超了提示「金额过大」
- 自动四舍五入到分：`0.005` → `0.01`

规则按《正确填写票据和结算凭证的基本规定》：

| 情况 | 结果 |
| --- | --- |
| 无角无分 | 加「整」——`1000000.00` → 壹佰万元整 |
| 有角无分 | 不加「整」——`1000000.5` → 壹佰万元伍角 |
| 有分无角 | 补「零」——`1.05` → 壹元零伍分 |
| 连续多个 0 | 只读一个「零」——`100005` → 壹拾万零伍元整 |
| 亿位、万位为 0 | `100000001` → 壹亿零壹元整 |

## 二、工作日计算

三块内容同屏，互相独立。

### ① 从某天起过 N 个工作日是哪天

- 选起始日，填 N，结果给出日期与星期
- 「含起始日」勾上的意思：起始日本身算第 1 个工作日
- 起始日落在周末时，自动从下一个工作日开始算
- N 填负数往前推

### ② 两个日期之间有几个工作日

同时给两种口径：**含端点**（两个日期都算）和**不含端点**。

结束日早于起始日时会提示「反向」，数字显示为绝对值。

### ③ 日期差

自然日 / 整月 / 整年 一起给，另外给「3 年 2 个月 5 天」这种描述，以及两端各是星期几。

### 节假日表

界面顶部会显示当前数据来源，内置数据标注为：

> 内置 2025–2026 节假日，截止 2026-11，可能已过期，请自行核对

- 点「编辑节假日表…」：左边填放假的日期，右边填周末要上班的补班日期，一行一个 `2026-10-01`
- 改乱了点「恢复内置 2025–2026」，把内置表重新填回两个框里（点「确定」才生效）
- 点「一键清空（只按周一到周五）」：清空后所有周末都不算工作日、所有工作日都算
- 改完立刻生效，下次打开还记得
- 如果整张表几乎天天都填成节假日，程序不会卡死也不会算出一个荒唐的年份，会直接提示你检查设置

## 三、含税 / 不含税

1. 选方向：**由含税算不含税**（发票金额是含税的）或**由不含税算含税**（报价场景）
2. 填金额
3. 填税率，或者点 `13% 9% 6% 5% 3% 1%` 快捷键；也能手填 `6.5` 这种任意小数

结果三行：不含税 / 税额 / 含税（都 2 位小数），下面灰字给 4 位小数的高精度值。

**关键点：不会差一分钱。**

程序先算基准值，另一个用加/减法得出：

- 由含税反推：先算不含税（四舍五入到分），税额 = 含税 − 不含税
- 由不含税正推：税额 = 不含税 × 税率（四舍五入到分），含税 = 不含税 + 税额

所以 `不含税 + 税额` 永远正好等于 `含税`，界面上会显示「一分不差」。

## 四、日期计算

### ① 两个日期相差多少

自然日、工作日（含端点）、整月、整年，外加两端的星期几。

### ② 从某天推 N 天 / 月 / 年

月末对齐：

| 起点 | 加 | 结果 |
| --- | --- | --- |
| 2026-01-31 | 1 个月 | 2026-02-28（2026 不是闰年） |
| 2028-02-29 | 1 年 | 2029-02-28 |
| 2026-12-31 | 1 天 | 2027-01-01 |

## 五、汇率换算

顶部固定一行提示：**汇率需手动输入，本工具不联网、不抓行情**。

1. 选源币种和目标币种（下拉里有 CNY USD EUR HKD JPY GBP，也可以直接手输任意代码）
2. 填金额、填汇率（1 源币种 = ? 目标币种）
3. 结果给出正向换算（4 位小数）和反算，反算用的是 `1/汇率`

「存为常用汇率」会把这一条存起来：

- 最多 20 条，最新的在最上面
- 同一币种对（包括反向，USD→CNY 与 CNY→USD 算同一对）只留最新一条
- 双击一条即填入
- 「清空常用」全删

## 数据存在哪

| 文件 | 位置 | 内容 |
| --- | --- | --- |
| `settings.json` | `%APPDATA%\MoneyCalc\` | 主题、税率、上次停在哪个计算器、节假日表、常用汇率（带 `Version`） |
| `app.log` | 同上 | 出错时才有内容，512 KB 轮转 |

写入走「`.tmp` → 原子替换 → `.bak`」，断电不会把配置写坏。想恢复出厂设置：关掉程序，删 `settings.json`。

## 常见问题

**Q：为什么没有「计算」按钮？**
A：输入变就出结果，少点一次是一次。

**Q：节假日算出来和公司不一致？**
A：内置数据是公开的法定安排，公司自己的调休可能不一样。点「编辑节假日表…」按你们的实际安排改。

**Q：含税反推怎么和我用 Excel 算的差一分钱？**
A：多半是 Excel 里两项各自四舍五入再相加。本工具保证 `不含税 + 税额 = 含税`，差额只会出现在「税额」上而不是两边都差。

**Q：汇率能自动更新吗？**
A：不能，也不打算做。要自动更新就得联网抓行情，这个工具的原则是不联网。
