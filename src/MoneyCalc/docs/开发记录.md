## 关键决策

### 1. 大写金额用 `long` 存「分」，全程整数

`decimal` 算钱没问题，但「分成角、分成元」这种拆位操作在浮点/小数上容易踩坑（尤其四舍五入的边界）。统一先 `Round(abs * 100)` 成 `long cents`，之后全是整数取余：

```
yuan = cents / 100;  jiao = cents / 10 % 10;  fen = cents % 10;
```

好处是「0.005 进到 0.01」这类边界只有一处逻辑；坏处是超过 `long` 范围就不能用了——反正金额上限是 999,999,999,999.99，安全。

### 2. 大写「零」的规则：分组 + 两个 pending 标志

中文大写最烦的是零：连续 0 只读一个、万位/亿位整组为 0 时不读「万」、末尾 0 不读。

实现上分两层：

- `GroupToChinese(group)`：处理 4 位以内的「仟佰拾个」，中间 0 补一个「零」，末尾 0 丢弃（靠 `pendingZero` 标志）
- `IntToChinese(value)`：按 4 位一组切成「个/万/亿」，组之间如果上一组是 0 或本组不足 4 位，补一个「零」

这样 `100000001`（壹亿零壹）、`100010000`（壹亿零壹万）、`100005`（壹拾万零伍）都能自然出来，不需要为每个特例写 if。

### 3. 含税换算：**只用一次四舍五入**

这是最容易出错的地方。错误做法是两个值各自四舍五入：

```
不含税 = round(含税 / 1.13)      // 1000.00
税额   = round(含税 * 0.13/1.13) // 129.99  ← 差一分
```

正确做法是先算基准值，另一个用加减法：

```
不含税 = round(含税 / 1.13)   → 1000.00
税额   = 含税 - 不含税        → 130.00
```

由不含税正推同理（税额先算，含税用加法）。测试里有一个用例把「0.01 / 1 / 99.99 / 1130 / 9999999.99 / 3333.33 / 7.77」×「0/1/3/5/6/9/13/6.5%」全跑一遍，逐个断言 `Net + Tax == Gross`。

### 4. 工作日：日历对象可替换，内置数据不是硬编码在算法里

`HolidayCalendar` 只是一个「节假日集合 + 补班集合」，`IsWorkday` 三行逻辑。内置的 2025/2026 数据是 `BuiltIn2025And2026()` 造出来的**一个实例**，随时可以换成用户编辑的表或 `WeekdaysOnly()`。

好处：测试全部用 `WeekdaysOnly()` + 手工加日期的日历，**测试结果不依赖内置数据是否准确**。这很重要——法定节假日每年都会调，算法不能跟着数据一起漂。

### 5. 反向计数返回负数

「结束日早于起始日」有几种处理：报错、返回 0、交换后返回正数。选了**返回负数**：数学上一致（计数是反对称的），界面上取绝对值并提示「反向」，用户能自己看出来填反了。

### 6. 汇率「同一对」包括反方向

`USD→CNY` 和 `CNY→USD` 视为同一对，只留最新一条。理由：用户换的都是同一件事，存两条只会让人困惑该点哪条。

### 7. 节假日数据的状态要显式存

第一版只有两张日期表，结果「一键清空」之后重启又被内置数据填回来了——因为空表没法区分「没配过」和「故意清空」。

修法：加 `UseBuiltInHolidays` 布尔。`true` = 用内置；用户一编辑或一清空就置 `false`，以后只认存下来的两张表。

## 踩过的坑

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| 「大金额也准」测试挂了，税额差 15 万 | 是我自己算错了：9999999.99 − 8849557.51 = 1150442.48 | 改测试期望（实现是对的） |
| 汇率正反算回不到原值 | 倒数只保留 4 位小数，7.1234 的倒数 0.1404 已经损失精度 | 改成用 2.0 这种倒数是精确值的汇率测「互逆」，另加一条测试明确「真实汇率来回换会差一点点」 |
| 清空节假日后重启又变回内置 | 空表无法区分「没配过」与「故意清空」 | 加 `UseBuiltInHolidays` 标志 |
| XAML 里同一个 `Workday_Changed` 绑 `TextChanged` 和 `SelectedDateChanged` | 两个事件参数类型不同 | 写成两个重载（`TextChangedEventArgs` / `SelectionChangedEventArgs`），XAML 按委托类型自动选 |
