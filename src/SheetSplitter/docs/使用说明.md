# 表格拆合器 · 使用说明

> 四个模式共用一套界面骨架：上面选源文件、中间设参数、下面选输出目录并执行。
> 版本 0.1.1，全中文，不联网。

---

## 通用部分

### 选文件

- 点「浏览…」，或者**直接把文件拖进窗口**
- 支持 `.xlsx` `.xlsm` `.csv` `.tsv`；`.xls` 不支持（会提示另存为 xlsx）
- 多 sheet 的文件会出现「工作表」下拉框，默认第一张

### 选输出目录（必填）

右下角「选择…」打开的是系统自带的文件夹对话框。**不选的话「开始执行」点不动**——这是故意的，避免手一抖把文件写到某个奇怪的目录里。

选了源文件之后，如果输出目录还空着，会自动填成源文件所在的目录，省一步。

### 三个按钮

| 按钮 | 作用 |
| --- | --- |
| 预览源表 | 弹窗看源表前 100 行，确认选对了列 |
| 预览计划 | 不写文件，只告诉你「将生成 N 个文件，共 M 行」，并列出前 15 个文件名 |
| 开始执行 | 真正写文件；完成后弹出结果，可以直接打开输出目录 |

### 重名怎么办

**不覆盖。** 目标文件已存在时自动加 `(1)(2)`，所以你可以在同一个目录里反复跑，不会丢上一次的结果。

## 模式 1 · 按列值拆分

最常用的一个：一张总表按「部门」「客户」「月份」拆成多个文件。

1. 选源文件 → 选工作表和「按哪一列拆」
2. 选输出方式：
   - **每个值一个文件**（默认）→ `总表_财务部.xlsx`、`总表_采购部.xlsx` …
   - **拆成同一个文件里的多个 sheet** → 一个 `总表_按列拆分.xlsx`，里面每个值一张 sheet
3. 勾「保留表头」（默认勾上）
4. 预览计划 → 开始执行

规则说明：

| 情况 | 结果 |
| --- | --- |
| 单元格是空值 | 归到 `总表_空白.xlsx`，排在最后 |
| 值里有 `\ / : * ? " < > \|` | 换成 `_`（比如「研发/测试部」→ `研发_测试部`） |
| 值超过 60 个字 | 截断到 60 个字（Windows 路径长度限制） |
| 值前后有空格或点 | 去掉 |

## 模式 2 · 多文件合并

把十几个文件、或者一整个文件夹里的表合成一张。

1. 「添加文件…」多选，或者「添加文件夹…」（勾「含子目录」会连子文件夹一起扫）
2. 选「取哪些 sheet」：
   - 每个文件的第一张（默认）
   - 每个文件的同名 sheet（在右边填 sheet 名，比如 `Sheet1`）
   - 每个文件的所有 sheet
3. 「表头对齐」：
   - **按列名**（默认）—— 列顺序不一样也没关系，按列名对
   - 按列位置 —— 第 1 列对第 1 列，列名不同也硬对
4. 勾「追加来源文件/sheet 两列」（默认勾上）—— 合并后能知道每一行来自哪个文件的哪张表
5. 预览计划 → 开始执行

对齐规则：

- **缺列**：这一格留空，并在预览里列出「a.xlsx - 缺列：金额」
- **多出来的列**：自动追加到右边，不会丢数据
- 合并结果写成一张 sheet，名字叫「合并结果」

## 模式 3 · 多 sheet 合并

一个文件里的多张 sheet 合成一张（比如 1~12 月的分月表在一个工作簿里）。

1. 选源文件 → 下面列出所有 sheet，勾选要合并的（默认全勾）
2. 可以用「全选 / 全不选」快速调整
3. 对齐方式、来源列同模式 2
4. 输出文件叫 `原名_sheet合并.xlsx`

---

## 模式 4 · 按行数拆分

大表按行切，方便分批发邮件。

1. 选源文件 → 选工作表
2. 填「每份最多 N 行」（默认 1000）
3. 预览计划会算出大约几个文件
4. 输出：`总表_第1份.xlsx`、`总表_第2份.xlsx` …

边界情况：

| 情况 | 结果 |
| --- | --- |
| 正好整除（300 行 / 100） | 3 个文件，各 100 行 |
| 余 1 行（301 行 / 100） | 4 个文件，最后一份 1 行 |
| N 大于总行数（50 行 / 500） | 只出 1 个文件 |
| 源表 0 行 | 不生成文件，提示「源表没有数据行」 |
| N 超过 Excel 单表上限 | 直接拦住，提示改小 |

每份都带表头。

## 常见问题

**Q：源文件会被改动吗？**
A：不会。程序只读源文件，输出一律写到你自己选的目录。有单元测试专门比对源文件执行前后的长度和修改时间。

**Q：合并后行数比预期少？**
A：看预览里的「缺列」提示；另外如果某个文件取 sheet 的策略是「第一张」，而数据在第二张，就会漏。改成「所有 sheet」再试。

**Q：提示「文件被占用或没有写权限」？**
A：目标文件正在 Excel 里开着，或者输出目录是只读的。关掉 Excel / 换个目录。

**Q：想按两列拆（比如部门 + 月份）？**
A：v0.1 只支持单列。可以先用 Excel 加一列辅助列把它们拼起来，再按那一列拆。

## 命令行（给脚本 / 验货用）

```
SheetSplitter.exe --maketestdata [目录]
```

生成一份 500 行的 `总表.xlsx`（12 个部门 + 1 行部门为空，其中一个部门叫「研发/测试部」用于验证文件名清洗）。
结果写在 `%APPDATA%\SheetSplitter\cli-result.txt`，不弹对话框，脚本可以直接读。
