# 表格比对器 · 使用说明

> 给财务、对账、录数据的人用：两张表放一起，一眼看出哪几行多了、哪几行少了、哪些字段被改过。
> 版本 0.1.1。界面全中文，不联网。

---

## 一、界面长什么样

窗口从上到下五块：

1. **标题条** —— 右边有「深色模式 / 浅色模式」切换
2. **两个文件槽** —— 左边「表 A」（改之前的表），右边「表 B」（改之后的表）
3. **比对方式与选项** —— 按什么比、主键是哪几列、要不要忽略大小写和空格
4. **操作条** —— 开始比对 / 取消 / 只看差异 / 搜索 / 导出
5. **结果区** —— 汇总数字 + 明细表格 + 底部状态栏

---

## 二、导入两张表

- **支持格式**：`.xlsx` `.xlsm` `.csv` `.tsv`
- **`.xls` 不支持**：会提示「请在 Excel 里另存为 xlsx」。老格式的读法跟新格式完全不同，硬读容易读出乱码数字，不如直接让你另存。
- **三种打开方式**：拖进窗口（一次拖两个文件会分别填 A 和 B）、点「浏览…」、拖到某个文件槽上
- **多工作表**：文件名后面会出现「工作表」下拉框，默认第一个；两个文件各选各的
- **CSV 编码自动判断**：有 BOM 按 BOM；没有 BOM 先按严格 UTF-8 试，不行就按 GB18030 读（Excel 里「另存为 CSV」在中文系统上默认就是 GB18030）
- **分隔符自动判断**：逗号 / 制表符 / 分号都认；`.tsv` 固定按制表符

读进来的单元格已经规整过：

| 原始 | 显示 |
| --- | --- |
| Excel 日期 `45292` | `2026-01-01` |
| 数字 `1.2000000000000002` | `1.2` |
| 公式单元格（没有缓存值） | `=SUM(A1:A9)` 原文，并写日志 |

## 三、选比对方式

| 方式 | 什么时候用 | 结果含义 |
| --- | --- | --- |
| **按主键**（默认） | 两张表都有唯一标识，比如单据号、工号、物料编码 | 仅A有 / 仅B有 / 字段变更 |
| **按行位置** | 没有主键的报表，靠第 N 行对第 N 行 | 同上，但按行号配对 |
| **按整行内容** | 只想问「这一行在另一张里到底有没有」 | 相同 / 仅A有 / 仅B有（不判字段变更） |

**按主键**时最多选 3 列做复合键（比如「单号 + 行号」）。下拉框里的选项是表 A 的表头，第二、三个可以留「（不用）」。

> 主键重复会警告：汇总条右侧出现「主键重复 N 处」，点开能看到具体是哪些键、A/B 两侧各出现几次。程序按第一条匹配，**不会静默吞掉**。

---

## 四、选项

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 忽略大小写 | 关 | `ACME` 与 `acme` 算相同 |
| 忽略首尾空格 | **开** | `" 甲公司 "` 与 `"甲公司"` 算相同 |
| 空单元格与空串视为相同 | **开** | 空格子与 `""` 算相同；与「有值」仍然算不同 |
| 忽略全空行 | **开** | 整行都是空白的行不参与比对，汇总里的行数也不含它 |
| 数值容差 | 0 | 填 `0.01` 表示相差 ≤ 1 分钱算相同。填 0 时按数值精确比较（`1000` 与 `1000.00` 仍然算相同） |

这些选项和上次打开的文件路径都会记住，下次打开自动还原（存 `%APPDATA%\TableDiff\settings.json`）。

---

## 五、列映射与忽略列

点「列映射 / 忽略列…」：

- 左栏是**表 A 的列**
- 中间下拉选它在**表 B 里对应的列**
- 右边「比对」勾掉 = 这一列只显示、不比较差异（比如「更新时间」「备注」这类天天变的列）

默认是按表头名自动匹配的；名字对不上（比如 A 叫「客户」B 叫「客户名称」）就手动指一下。B 独有、A 没有的列会以「xxx（仅B）」出现在最后。

映射改完要**重新点一次「开始比对」**才生效。

---

## 六、看结果

**汇总条**：A 行数 / B 行数 / 相同 / 仅A / 仅B / 差异行 / 差异单元格。

**明细表**：

| 状态 | 颜色 | 含义 |
| --- | --- | --- |
| 相同 | 灰 | 两边一样 |
| 有差异 | 红字 + 黄色单元格 | 该行的某些字段变了 |
| 仅A有 | 红字 | B 表里没有这个键 |
| 仅B有 | 绿字 | A 表里没有这个键 |

> 这里的红绿是 **diff 语义色**（差异/缺失），不是股票行情的「涨红跌绿」。全库只有金额涨跌才用涨跌色。

改过的单元格显示成 `200 → 250`（整数带千分位），鼠标悬停能看到完整旧值、新值，以及它在 A、B 里分别是第几行。

**过滤与搜索**：

- 右上「全部行 / 只看差异」切换
- 搜索框按**任意列包含匹配**，大小写不敏感

## 七、导出

| 按钮 | 产出 | 说明 |
| --- | --- | --- |
| 导出差异清单… | `差异清单_20261114_2240.csv` | UTF-8 **带 BOM**，Excel 双击直接打开不乱码 |
| 导出差异报告… | `差异报告_20261114_2240.xlsx` | 两个 sheet：「汇总」+「差异明细」，明细里保留黄色高亮和红/绿字 |

CSV 列固定：`序号,类型,主键,列名,表A值,表B值,说明`

- 仅A有 / 仅B有 的行：列名写「（整行）」，说明里给出行号
- 字段变更：一行一个单元格，说明里写「A 第 12 行 / B 第 5 行」

---

## 八、大文件

5 万行 × 50 列的规模是在后台线程跑的，界面不卡：

- 底部有进度条，可以随时点「取消」
- 读不出的单元格（公式没缓存值、怪格式）降级成公式文本并写日志，不会让整次比对失败

---

## 九、数据存在哪

| 文件 | 位置 | 内容 |
| --- | --- | --- |
| `settings.json` | `%APPDATA%\TableDiff\` | 上次的文件、选项、主题、列映射（带 `Version` 字段） |
| `settings.json.bak` | 同上 | 上一次的配置（读坏了自动回滚） |
| `app.log` | 同上 | 运行日志，512 KB 轮转成 `app.1.log` |

写入一律「`.tmp` → 原子替换 → `.bak`」，断电不会把配置写坏。想恢复出厂设置：关掉程序，删掉 `settings.json` 即可。

## 十、常见问题

**Q：提示「文件被 Excel 占用了，请先关闭再试」？**
A：这个文件正在 Excel 里开着。关掉 Excel 再试（不用重启程序）。

**Q：中文全是乱码？**
A：CSV 的编码判断错了。请在 Excel 里「另存为」→「CSV UTF-8（逗号分隔）」再试。

**Q：日期显示成一串数字？**
A：说明源文件里那一列是文本格式的数字。程序只把**真正的日期单元格**转成 `yyyy-MM-dd`，文本 `45292` 会原样显示。

**Q：只想看差异，不想翻几百行相同的。**
A：右上角下拉选「只看差异」。

**Q：比对完发现主键选错了。**
A：换主键列，再点一次「开始比对」，几秒钟的事。

## 十一、快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl + O` | 选表 A |
| `Ctrl + Shift + O` | 选表 B |
| `F5` | 用当前设置重新比对 |
| `Ctrl + E` | 导出差异清单（CSV） |
| `Ctrl + Shift + E` | 导出差异报告（xlsx） |

导出 CSV 时，值以 `=`、`@` 开头（或 `+`/`-` 开头的非数字）会自动在前面加一个单引号，防止 Excel 把它当公式执行。纯数字的负值（如 `-100`）不受影响。

---

## 十二、命令行（给脚本 / 验货用）

```
TableDiff.exe --maketestdata [目录]
```

在指定目录（不写就是 `%APPDATA%\TableDiff`）生成 `表A.xlsx` 与 `表B.xlsx`，用于试手和验收。
**结果不弹对话框**，写在 `%APPDATA%\TableDiff\cli-result.txt`，脚本可以直接读，不会卡在等人点「确定」。
