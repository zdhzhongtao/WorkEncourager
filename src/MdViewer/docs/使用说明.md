# Markdown 阅读器 · 使用说明

> 双击 `.md` 或 `.epub` 就能看，排版按阅读优化，不联网。
> 版本 0.4.0。

---

## 〇、装到本机

在仓库里跑一次（只写当前用户，不需要管理员）：

```powershell
.\src\MdViewer\install.ps1
```

它会做四件事：

1. 编译出单文件 exe，装到 `%LOCALAPPDATA%\Programs\MdViewer\MdViewer.exe`
2. 建开始菜单快捷方式，以及桌面快捷方式（不想放桌面就加 `-NoDesktop`）
3. 把 `.md` / `.markdown` / `.mdown` 的默认打开程序设成本程序
4. 通知资源管理器刷新图标

编译哪种版本由 `-Mode` 决定，默认 `auto`：

| 模式 | 大小 | 说明 |
| --- | --- | --- |
| `auto`（默认） | 看情况 | 本机装了 .NET 10 桌面运行时就用 `local`，否则用 `portable` |
| `local` | ~2 MB | 依赖本机的 .NET 10 桌面运行时，自己用首选 |
| `portable` | ~60 MB | 自带运行时，发给别人、拷到别的机器都能直接跑 |

```powershell
.\src\MdViewer\install.ps1 -Mode portable
```

**关于抢默认程序这件事**：装之前它会读一下原来是谁占着，把原值记在 `%APPDATA%\MdViewer\assoc-backup.json`。
比如你机器上原来是 `WorkBuddy.md`，装完会提示「顶掉了原来的默认程序：.md（原来是 WorkBuddy.md）」，
以后跑 `install.ps1 -Uninstall` 会自动还原回去。

不想抢就加 `-KeepExisting`，那样只在右键菜单里加一项「用 Markdown 阅读器 打开」，默认程序不动。

卸载：

```powershell
.\src\MdViewer\install.ps1 -Uninstall
```

> 如果装完双击 md 还是弹「选择应用」，说明系统里还留着旧的 UserChoice 记录（Win10/11 不让程序静默接管）。
> 右键那个 md → 打开方式 → 选择其他应用 → 选「Markdown 阅读器」→ 勾「始终使用」。这一步只能人手动点。

### 内存会占多少

| 状态 | 进程数 | 工作集 |
| --- | --- | --- |
| 开着窗口但没打开文件 | 1 | 约 97 MB |
| 打开一个 md 之后 | 7 | 约 480 MB |

从 0.2.0 起，WebView2 是**打开文件时才创建**的。所以平时挂着很轻，看文档时才付出渲染成本；
关掉窗口 7 个进程全退，不会残留。想省内存就别同时开一堆大 md 窗口——每个窗口是独立的一套。

## 一、四种打开方式

| 方式 | 做法 |
| --- | --- |
| 拖进来 | 把 md / epub 文件拖到窗口上（可拖到 exe 图标上） |
| 命令行 | `MdViewer.exe "C:\我的 文档\说明.md"`（路径带空格要加引号；不带引号、带引号都能识别） |
| 工具栏 | 点「打开」，默认停在上次浏览的目录 |
| 最近文件 | 点「最近 ▾」或按 `Ctrl+E`，见下面「最近打开」 |

**单实例**：已经开着一个窗口时，再从资源管理器双击 md，不会弹出第二个窗口，而是把文件送到已有窗口里打开。

没打开任何文件时是起始页，上面有「打开文件」「看样例」两个按钮，下面直接列出最近打开过的 6 份文档，双击即可打开。

### 最近打开

点工具栏「最近」（或 `Ctrl+E`）会掉出一个面板：

- 每一行是「文件名 + 所在目录」，右边是「刚刚 / 3 分钟前 / 昨天」这样的相对时间
- 顶部可以直接打字过滤，输入文件名或路径片段都行
- `↑` `↓` 选，`Enter` 打开，`Del` 把这一条从列表里去掉，`Esc` 关闭
- 文件被删掉或移走的那条会变成灰色的「xxx.md（已删除）」，点它会问你要不要从列表里移除。
  **不会自动清理**——留着让你知道自己读过什么
- 最多记 12 条，最新的排最前

- **滚动条**：正文和侧栏都是细圆角样式，不再是系统那种带上下箭头的。
- **阅读进度**：正文顶部有一条 3px 的进度条，滚动时显示，不挡内容。

## 四、自动刷新（这一版重点）

文档被别的程序改动后**自动**重新渲染，不用手动点刷新。触发场景：

- 在 VS Code / Typora / 记事本里改完保存
- `git pull` / `git checkout` 换分支把这个文件改了
- OneDrive / 坚果云同步下来新版本

处理细节：

- 改动后等 0.42 秒才读（编辑器保存往往连写好几次，防抖避免反复渲染）
- 如果读的时候文件正被占用，会重试 3 次
- **保持你读到的那一行**：重渲染前记下滚动比例，新页面加载完再跳回去
- 内容没变就什么都不做（编辑器每次自动保存不会让页面闪）
- 状态栏右侧会闪一下「已自动重新载入」

不想要这个行为：设置 → 阅读 → 取消勾选「文件被别的程序改动后自动刷新」。
手动刷新随时可用：工具栏 ⟳ 按钮 / `F5` / 「更多 → 重新读取」。

文件被删除或改名时，页面内容保留，状态栏提示「文件被删除或移走了」，不会白屏。

### 记忆阅读位置

同一篇文档关掉再打开，会回到上次读到的位置（按比例记，窗口大小变了也对得上）。
不喜欢就在设置里关掉「重新打开同一篇文档时回到上次读到的位置」。

## 五、EPUB 电子书

`.epub` 文件可以直接拖进来，或者「打开」时选它。

- 支持 EPUB 2（`toc.ncx`）和 EPUB 3（`nav.xhtml`）两种目录
- 按书里的 `spine` 顺序把章节合并成一整页，左侧目录栏显示书的章节结构
- 书里的图片、表格、代码块、脚注都保留
- **书自带的 CSS 会被丢掉**：绝大多数 epub 是给 6 寸墨水屏排的，字体行高全是死值，
  套到桌面窗口反而更难读，所以统一用本程序的排版。代价是出版社的花哨版式会没有
- 第一次打开大书要解压（几百毫秒到几秒），之后走缓存；缓存只留最近 3 本

## 六、设置

`Ctrl+,` 或工具栏 ⚙ 打开。所有改动**立即生效、立即保存**，没有「取消」。

| 分区 | 内容 |
| --- | --- |
| 外观 | 深浅模式（跟随系统 / 浅色 / 深色）、浅色时用哪套主题、深色时用哪套主题、正文字号 14~22、正文宽度 640~1400px |
| 阅读 | 自动刷新开关、记忆阅读位置、默认显示目录 |
| 文件关联 | 当前状态 + 关联 / 取消关联按钮 |
| 更新 | 当前版本、发布仓库、启动时检查、检查更新 / 下载并安装 / 跳过这个版本 |
| 重置 | 「恢复默认设置」一键回到出厂值 |
| 关于 | 版本、数据目录（可直接打开）、日志 |

### 检查更新

只有你点「检查更新」时才会联网（默认不勾「启动时检查」）。流程：

1. 访问 `https://api.github.com/repos/<仓库>/releases/latest`
2. 拿 `tag_name` 里的版本号和当前版本比
3. 有新版且 Release 里带 `.exe` 附件，就显示「下载并安装」
4. 下载完会关掉本程序、把旧 exe 改名成 `.old`、新 exe 就位、自动重新打开

仓库地址默认为 `zdhzhongtao/WorkEncourager`，在设置里可以改成任意 `owner/repo`。
点了「跳过这个版本」之后不会再提示同一个版本。

> 如果本程序装在 `Program Files` 之类需要管理员权限的位置，替换会失败 ——
> 那种情况下按提示手动把下载好的 exe 复制过去覆盖即可。装到 `%LOCALAPPDATA%` 没有这个问题。

### 恢复默认设置

设置 → 重置 → 「恢复默认设置」。会把**外观**（明暗、两套主题、字号、正文宽度、宽屏）、
**阅读开关**（自动刷新、记忆位置、默认显示目录）、**更新配置**（仓库地址、启动时检查、
跳过的那一版）全部还原成出厂值。

**保留**：最近打开、每篇读到的位置、上次打开的目录、窗口大小与目录宽度、`.md` 关联状态 ——
这些是使用痕迹，不是设置，一并抹掉只会白丢东西。

重置前会自动把当前 `settings.json` 复制一份到数据目录，文件名 `settings-<时间戳>.bak.json`，
只留最近 5 份。改坏了想退回旧配置，把某份改名回 `settings.json` 即可。

## 八、导出

### PDF

`Ctrl+P` → 选保存位置。四边 12mm 边距、打印背景色（代码块底色、引用底色都会保留）。导出完可以直接打开看。

- 普通模式：A4 竖版（8.27 × 11.69 英寸），宽度锁在阅读栏，跟屏幕上一行读起来的感觉一致
- **宽屏模式：A4 横向（11.69 × 8.27 英寸）**，宽表横着铺开，30 列不会在纸上被挤成一条条

### HTML

「导出 HTML」生成一个**单文件** html：样式全部内联，双击就能在浏览器里正常显示。

- 普通模式：正文宽度沿用设置里的宽度（默认 880px），居中，适合读
- **宽屏模式：不设宽度上限，铺满浏览器窗口**（左右留白也收窄），多列表格直接在浏览器里横向滚动

> 图片保持相对路径（只把 `.\img\a.png` 这种反斜杠写成 `img/a.png`），所以**记得把 `images` 目录跟 html 一起拷走**，否则图片是空的。

### 导出完成后

不会弹框拦你。右下角浮一条通知，写着导出了哪个文件，6 秒左右自己消失：

- 鼠标移上去就停住不消失，方便你去点
- 「打开」直接用默认程序打开刚导出的文件
- 「所在文件夹」在资源管理器里定位并选中它
- 点右上角 ✕ 立刻关掉

失败才弹框（那种确实需要你看一眼原因）。

## 九、主题与字号

### 10 套主题

工具栏的调色板按钮（月亮 / 太阳图标）点开会列出全部主题，分浅色、深色两组：

| 浅色 | 深色 |
| --- | --- |
| GitHub 浅色 | GitHub 深色 |
| Vue 绿 | Nord |
| Solarized 浅 | Dracula |
| 护眼米黄 | One Dark |
| 报纸衬线 | Solarized 深 |

- 点一下立即切换，**只换 CSS 变量不重新渲染**，所以滚动位置不会跳回顶部，也不会闪一下白屏
- 每套主题自带主色，界面（「打开」按钮、目录选中项、阅读进度条）会跟着变，
  不会出现「深色正文配一套刺眼的浅色界面」
- 两套特殊主题：**护眼米黄**是暖白底 + 墨棕字，夜里读长文最省眼；
  **报纸衬线**换成衬线字体、行距 1.85、圆角收到 2px，读起来像纸质书
- 深色主题下给浅底图片自动加一圈细描边，白色截图不至于刺眼

### 跟随系统

设置 → 外观 → 深浅模式里选「跟随系统」，程序会跟着 Windows 的「应用模式」**实时**切 ——
在 Windows 设置里改完，窗口立刻变，不用重启。

同一页还能分别指定「浅色时用哪套」和「深色时用哪套」，比如浅色用 GitHub、深色用 Nord。
两个下拉各自只列对应明暗的主题，选不出「深底配深字」这种组合。

`Ctrl+Shift+D` 是快切，跳的是**同一套主题的明暗版本**（`github-light` ↔ `github-dark`、
`solarized-light` ↔ `solarized-dark`）。没有配对的主题（护眼米黄、Nord、Dracula 这些）
会跳到对应明暗的默认主题。

### 其他

- 导出 PDF / 打印时一律强制浅色（深色底打出来是一片墨，PDF 阅读体验也差）
- 字号记忆在 `%APPDATA%\MdViewer\settings.json`，只影响正文（标题按比例跟着缩放），不影响工具栏
- 正文宽度（640~1400px）在设置里调，控制每行字数
- **列多的表格**（比如 30 列的对账表）：每列有最小宽度，放不下时表格自己出横向滚动条，
  不会把每格压成一个字一行。想一屏看到更多列，点工具栏的「宽屏」（`Ctrl+Shift+W`）——
  正文铺满窗口、目录自动收起，再点一下还原
- 主题 id 也存在 `settings.json` 里（`LightThemeId` / `DarkThemeId`），手工改成不存在的值会自动回落到默认主题

## 十、图片与链接

- **相对路径图片**必须能显示：`./img/a.png`、`../b.png` 都支持（程序把 md 所在目录映射成一个内部域名来加载）
- 图片加载失败会显示虚线占位框 + alt 文字，不会留一片空白
- 点**别的 md 链接**在当前窗口打开目标文件；点 **http(s) 链接**用系统默认浏览器打开
- **锚点链接**（`[跳到表格](#表格)`）在页面内跳转
- md 里写的 `https://…` 远程图片**不会被下载**（本工具零联网），会显示「加载失败」

## 十一、设成默认打开方式（用户最在意的一步）

有两条路，效果一样：

**A. 跑安装脚本（推荐，一步到位）**

```powershell
.\src\MdViewer\install.ps1
```

会顺带把程序装好、建快捷方式、设关联，并把你机器上原来的关联记进备份（卸载时还原）。

**B. 点界面上的「关联 .md」**

1. 点右上角「关联 .md」
2. 会写三个扩展名：`.md`、`.markdown`、`.mdown`，全部在 `HKCU`（当前用户）下，**不需要管理员**
3. 验证：命令行跑 `reg query "HKCU\Software\Classes\.md"`，能看到默认值是 `MdViewer.md`

**两种方式共同的注意事项**

- **Windows 10/11 不允许程序静默抢默认程序**。如果双击 md 还是被别的程序打开，请：
  右键文件 →「打开方式」→「选择其他应用」→ 勾「始终使用此应用」→ 选「Markdown 阅读器」
  这一步只能人手动点，任何程序都绕不过去。
- 想撤销就点「取消关联」：**只删自己写的键**（自己的 `MdViewer.md` 子树，以及那三个扩展名在还指向本程序时才清掉），不动别人的 ProgId。
- 如果 `.md` 已经被别的程序占着，0.2.0 起的脚本**不会再硬抢**之后再装作没事——它会明确告诉你「顶掉了原来的默认程序：.md（原来是 xxx）」。
  不想抢就加 `-KeepExisting`，那时只加右键菜单项。

已关联时按钮变灰、左边显示「已关联 ✓」。

## 十二、没有 WebView2 运行时怎么办

Win11、以及装了新版 Edge 的 Win10 一般自带 WebView2 运行时。万一没有：

- 程序不会白屏，会显示一段中文说明 + 「去下载 WebView2」按钮（这是全程序唯一会联网的地方，点了才跳浏览器）
- 同时把 md 当纯文本显示在窗口里，至少能看内容
- 装完运行时重启本程序，排版显示自动恢复

## 十三、数据放在哪

`%APPDATA%\MdViewer\`

| 文件 / 目录 | 内容 |
| --- | --- |
| `settings.json` | 主题、字号、正文宽度、最近打开（含时间）、阅读位置、更新设置、窗口大小 |
| `settings.json.bak` | 上一次的配置（写坏了能回退） |
| `app.log` | 运行日志（超过 512KB 自动转 `app.1.log`） |
| `WebView2\` | WebView2 的用户数据目录 |
| `cache\` | 每次渲染出来的整页 html（只留最近 20 个） |
| `epub\` | EPUB 解压出来的图片和章节（只留最近 3 本） |
| `update\` | 自动更新下载下来的新版本 exe |
| `assoc-backup.json` | 安装时顶掉的默认关联原值，卸载时还原用 |
| `demo.md` + `images\demo.svg` | `--demo` 生成的样例 |

卸载 = 删掉 exe 和这个目录，不写注册表以外的东西。

## 附：快捷键与缩放

| 操作 | 作用 |
| --- | --- |
| `Ctrl + O` | 打开文件 |
| `Ctrl + F` | 搜索（`Enter`/`Shift+Enter` 上下条，`Esc` 关闭） |
| `Ctrl + P` | 导出 PDF |
| `Ctrl + +` / `Ctrl + -` | 放大 / 缩小正文字号 |
| `Ctrl + 0` | 字号回到 16 |
| `Ctrl + 滚轮` | 在正文上滚动时调字号（不会缩放图片） |
| `F5` | 重新读取当前文件（外部改过内容时用） |

换主题只换配色，不会把滚动位置弹回顶部。`cache\` 目录每次启动会自动只留最近 20 个渲染结果。

点「关联 .md 文件」时，如果某个扩展名已经被别的程序占着默认值，**不会去抢**，只登记成「可选用本程序打开」，并如实告诉你哪几个没抢到。
