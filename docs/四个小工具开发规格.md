## 1 全局硬规矩（4 个工具全部适用，违反任何一条算没做完）

- .NET 10 + WPF；`<Nullable>disable</Nullable>`、`<ImplicitUsings>disable</ImplicitUsings>`，跟现有工具保持一致
- 每个工具三个项目：`src/<T>/<T>.csproj`（WinExe + WPF）、`src/<T>/<T>.Core/`（net10.0 类库，**不引用 WPF**）、`src/<T>/<T>.Tests/`（net10.0 xunit）
- 运行数据只写 `%APPDATA%\<exe名>\`，绝不写仓库目录
- 任何持久化写入走「`.tmp` → `File.Replace` → `.bak`」，照抄 `AtomicFile.cs`
- 界面文案全中文，按钮动词开头（"开始比对""导出差异清单"），报错说人话（"文件被 Excel 占用了，请先关闭再试"）
- 不使用第三方 UI 控件库，DataGrid / ListBox 全用 WPF 内置
- **零网络请求**。唯一的例外是 MdViewer 里用户主动点"去下载 WebView2 运行时"时用默认浏览器打开微软官方页面
- 工具之间不互相引用（禁止 `ProjectReference` 到别的工具）。需要共享代码时**复制文件过去**
- 每个工具的设置页要有明确的"退出"入口；关窗口直接退出（这 4 个都没有后台驻留需求）
- 耗时操作（读大文件、算几万行）必须在 `Task.Run` 里跑，UI 不卡，有进度提示
- 版本号一律 `0.1.0`
- 不 `git push`、不打 tag、不 `--amend`（本地 commit 见第 4 节）
- 写代码用 `pwsh` 跑 `dotnet build / test / publish`

## 4 执行顺序、阶段门、进度文件（重要）

依次做 A → B → C → D，**不要并行、不要跳序**。B 要复制 A 的读表代码，C 最轻用来回血，D 完全独立放最后。

**阶段门（每个工具必须全绿才允许进下一个）：**

1. `dotnet build WadeToolbox.slnx -c Release` → 0 警告 0 错误
2. `dotnet test src/<T>/<T>.Tests/<T>.Tests.csproj` → 全通过，用例数达标
3. `dotnet publish src/<T>/<T>.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true` → exe 能起
4. 按第 5~8 节该工具"验收"清单里的一次性手动验证全部走通
5. 该工具的 `docs/使用说明.md`、`docs/开发记录.md`、`README.md` 已写完

**某一步连续两轮修不好**：不要带着半坏代码硬冲。把该工具退化到"已完成的部分可用"（能编译、测试能过、界面能开），在 `PROGRESS.md` 记下"未完成项 + 卡在哪 + 建议"，继续做下一个工具。四个工具全部"能编译能跑"的价值，远大于一个工具做到完美。

**本地 commit（每过一个阶段门就提交一次，方便回滚）：**

```

```

## 5 工具 A · TableDiff 表格比对器（1080 宽 WPF）

给财务和做对账的人用：同时打开两张表，按业务主键找出「多了哪些行、少了哪些行、哪些字段被改过」。

### 5.1 导入
- 上下两个文件槽（表 A / 表 B），都支持拖放 + "浏览"按钮
- 支持 `.xlsx .xlsm .csv .tsv`；遇到 `.xls` 明确提示"这个格式读不了，请在 Excel 里另存为 xlsx"
- 多 sheet 文件给下拉选 sheet，默认第一个
- CSV/TSV 自动判分隔符（逗号/制表符/分号）+ 编码探测：有 BOM 按 BOM；无 BOM 先严格 UTF-8 解码，失败退 GB18030
- Excel 日期单元格转成 `yyyy-MM-dd`（别让用户看到 45292），数字去掉浮点尾巴（`1.2000000000000002` → `1.2`）

### 5.2 比对方式（单选）
- **按主键**：选 1~3 列组成复合键 → 报「仅A有 / 仅B有 / 字段变更」
- **按行位置**：第 N 行对第 N 行（没有主键的报表用）
- **按整行内容**：只判断"这行在另一张里有没有"
- 主键重复必须警告并列出重复键值，不许静默取第一条

### 5.3 列与选项
- 默认按表头名匹配；支持手动映射（A 哪列对 B 哪列）、"忽略此列"勾选
- 选项：忽略大小写、忽略首尾空格、数值容差（默认 0，可填 0.01）、空单元格与空串视为相同、忽略全空行
- 选项与上次选的文件路径存 `settings.json`

### 5.4 结果
- 汇总条：A 行数 / B 行数 / 相同 / 仅A / 仅B / 有差异行数 / 差异单元格数
- DataGrid：行级状态 + 单元格级高亮。**配色用 diff 语义色，不用涨跌色**：差异=黄底 `#FEF3C7`、仅A=红字 `#DC2626`、仅B=绿字 `#16A34A`（在开发记录里写明这个例外）
- 单元格显示改动前后："1,200 → 1,500"，tooltip 给完整值
- 过滤：全部 / 只看差异；顶部搜索框按任意列包含匹配

### 5.5 导出
- `差异清单.csv`：UTF-8 **带 BOM**，列固定 `序号,类型,主键,列名,表A值,表B值,说明`
- `差异报告.xlsx`：ClosedXML 写，两个 sheet「汇总」+「差异明细」，明细保留高亮填充
- 导出用 SaveFileDialog，默认文件名 `差异清单_yyyyMMdd_HHmm.csv`

### 5.6 稳定性
- 5 万行 × 50 列在后台线程比对，有进度文字 + 取消按钮
- 读不出的单元格（公式无缓存值、怪类型）降级为显示公式文本 + 写日志，不中断
- `TableDiff.exe --maketestdata <目录>`：生成一对样例 xlsx（各 200 行，含 3 处改值 / 2 行新增 / 1 行删除），方便手动验收

### 5.7 测试（≥25）
主键匹配（单键/复合键/仅A/仅B/字段变更/重复键告警）、数值容差（0.001 在 0.01 内判同、超容差判异、字符串与数字等价）、忽略列/大小写/首尾空格/空串等价/全空行、CSV（引号内逗号与换行、分号分隔、GB18030、无 BOM UTF-8、中文表头）、Excel 日期与数字格式化、导出（CSV 行数与列序、BOM 存在、xlsx 明细行数）、按行位置（两边行数不等）。

### 5.8 验收
用 `--maketestdata` 造数据 → 打开比对 → 汇总数字对得上（3 改 / 2 增 / 1 删）→ 导出 CSV 和 xlsx 都能被 Excel 正常打开且颜色正确 → `%APPDATA%\TableDiff\` 下出现 settings.json 与 app.log。

## 6 工具 B · SheetSplitter 表格拆合器（900 宽 WPF）

财务月结用：一张总表按部门拆成 12 个文件；12 个月的表合成一张；多个 sheet 合并；一张大表按行数切开分批发邮件。

### 6.1 复用 A 的读表代码
把 `src/TableDiff/TableDiff.Core/` 里的 Excel/CSV 读取、编码探测、日期转换、原子写、Log 相关文件**复制**到 `SheetSplitter.Core`，改命名空间。**不要 ProjectReference 到 TableDiff，也不要回头改 TableDiff**。复制后如果发现 A 的代码有 bug，两边各自修。

### 6.2 四个模式（TabControl 或左侧导航）
**模式 1 · 按列值拆分（最常用）**
- 源文件 → sheet → 选"按哪一列拆" → 每个不同值产出 `{原文件名}_{值}.xlsx`
- 文件名清洗：`\ / : * ? " < > |` 替换为 `_`，去首尾空格和点，超 60 字符截断
- 空值归到 `{原文件名}_空白.xlsx`；每个输出保留表头（可勾"不含表头"）、保留原 sheet 名
- 可选"按值拆成多个 sheet 而不是多个文件"
- 执行前先显示"将生成 12 个文件"的预判，用户确认后才写

**模式 2 · 多文件合并成一张**
- 加多个文件，或选一个文件夹（可选含子目录）
- sheet 策略：每个文件第一张 / 每个文件同名 sheet / 每个文件所有 sheet
- 表头对齐：按列名（默认）或按列位置；缺列留空并列出"文件名 - 缺哪列"；多出的列追加到末尾
- 追加 `来源文件` `来源sheet` 两列（可关）；输出一张新 xlsx，sheet 名「合并结果」

**模式 3 · 单文件多 sheet 合并**
- 同一文件的多个 sheet 合成一张，其余同模式 2

**模式 4 · 按行数拆分**
- 每份最多 N 行，`{原文件名}_第{i}份.xlsx`
- 边界：0 行 / 正好整除 / 余 1 行 / N 大于总行数（只出 1 份）
- 单个输出超过 1,048,576 行要提前警告，不许写出坏文件

### 6.3 通用安全
- 输出目录必须用户选，未选则"开始执行"禁用并提示
- 重名不覆盖，自动加 `(1)(2)`
- 先写 `<目标>.tmp` 再 rename；中途失败不留半个文件，列失败清单（文件/sheet/原因），其余继续
- 输出目录与源文件目录相同时警告；**源文件只读不写，任何情况都不许覆盖或移动**
- 后台执行 + 进度条 + 取消；完成后给"打开输出目录"
- 结果页：生成 N 个文件、共 M 行、跳过 K 个（含原因）
- 执行前可预览源表前 100 行 + 每个输出文件的预估行数
- `SheetSplitter.exe --maketestdata <目录>`：生成一张 500 行、含 `部门` 列（12 个部门，其中 1 行空值、1 个部门名含 `/`）的样例表

### 6.4 测试（≥20）
文件名清洗（非法字符/超长/空值/纯中文/前后空格）、按列值分组（正常/空值/单值/含空格与点）、表头对齐（列序不同/缺列/多列/按位置）、按行数拆分边界（0/整除/余1/N>总数/超 Excel 上限判断）、重名处理、原子写（异常时目标文件不存在）、CSV 编码（GB18030 / UTF-8 BOM）。

### 6.5 验收
四个模式各走一遍：500 行 → 拆成 13 个文件（含 2 个特殊：`_空白`、非法字符名）→ 都能打开 → 再合并回一张，行数与内容对得上 → 单文件多 sheet 合并 → 按 100 行切分。**确认源文件修改时间与大小未变。**

## 7 工具 C · MoneyCalc 财务小算盘（820 宽 WPF）

纯计算，不联网，不开文件。五个计算器用左侧导航切换，右侧结果区，**输入变即时出结果，不要"计算"按钮**。

### 7.1 人民币大写
- 输入接受千分位逗号、小数点、负数；上限 999,999,999,999.99，超范围提示"金额过大"
- 照《正确填写票据和结算凭证的基本规定》：壹贰叁肆伍陆柒捌玖、拾佰仟万亿、元角分整零
- 关键规则：连续 0 只读一个"零"；万位/亿位为 0 时零的处理；无角无分加"整"；有角无分不加"整"；分位为 0 不读"零分"
- 大字号显示 + 一键复制

### 7.2 工作日计算（三个子功能同屏）
- 起始日 + N 个工作日 → 结果日期（可选含/不含起始日）
- 两日期之间的工作日数（含端点/不含端点两种口径都显示）
- 日期差：自然日 / 工作日 / 整月 / 整年 同时给
- 节假日表可编辑（法定节假日 + 调休补班），存 `settings.json`，提供"一键清空，只用周一到周五"
- 内置 2025/2026 中国法定节假日与调休数据，但界面必须标注："内置节假日数据截止 2026-11，可能已过期，请自行核对" + 编辑入口
- 结果显示星期几

### 7.3 含税 / 不含税
- 金额 + 税率（快捷 13/9/6/5/3/1% + 自定义任意小数）
- 两个方向：由含税算不含税、由不含税算含税（分段按钮切换）
- 输出三行：不含税 / 税额 / 含税，均 2 位小数
- **舍入必须自洽**：先算基准值，另一个用减法得出，不许各自四舍五入后差一分
- 另给小字灰色 4 位小数高精度值

### 7.4 日期差 / 日期推算
- 两日期 → 相差天数、工作日数、整月数、整年数
- 日期 + N 天/月/年（月末对齐：1月31 + 1月 = 2月28/29，不是 3月3）
- 显示两个日期各自星期

### 7.5 汇率换算
- 源/目标币种（常用 CNY USD EUR HKD JPY GBP，也可手输任意代码）+ 手输汇率
- 双向换算，4 位小数，正反算都显示
- "常用汇率"保存最近 20 条（币种对 + 汇率 + 时间），点一条即填，可删单条、可清空
- 顶部固定一行："汇率需手动输入，本工具不联网、不抓行情"

### 7.6 通用
- 每个计算器有"复制结果"按钮（复制纯数字/纯文本，不带界面标签）
- Enter 跳下一个输入框；Ctrl+C 复制结果区
- 结果数字用 Consolas 等宽

### 7.7 测试（≥40，本工具的核心价值就在这）

## 8 工具 D · MdViewer Markdown 阅读器（1200 宽 WPF）

替代"用 VS Code 看 md"。双击 `.md` 直接打开，排版好看（类 GitHub 但更舒服）、目录侧栏、页面内搜索、导出 PDF，浅深两套主题。

### 8.1 技术选型（已定，不要改）
- 解析：**Markdig**（MIT），pipeline 用 CommonMark + GFM 扩展（表格、任务列表、删除线、脚注、自动链接）
- 渲染：**WebView2**（`Microsoft.Web.WebView2`）。本机已确认装有 WebView2 Runtime 157
- 安全：md 里的内联 HTML 要清洗 —— 剥掉 `<script>`、`on*` 事件属性、`javascript:` 链接、`<iframe>`；自己注入的 JS 只走 `postMessage` 通道
- WebView2 运行时缺失：不允许白屏。弹中文说明 + "去下载"按钮，并降级把 md 当纯文本用 WPF 显示
- WebView2 用户数据目录设到 `%APPDATA%\MdViewer\WebView2`

### 8.2 打开文件
- 命令行：`MdViewer.exe "C:\path\a.md"`（含空格、带引号都要对）
- 拖放、工具栏"打开"、最近 10 个文件菜单（去重、最新在上、存 settings.json、不存在的灰显并自动剔除）
- 单实例：第二次启动不新开窗口，把路径转发给已有窗口（命名 Mutex + 命名管道）
- 无参数启动显示欢迎页（拖入 md 试试 / 打开文件 / 怎么设成默认程序）
- `MdViewer.exe --demo` 在 `%APPDATA%\MdViewer\demo.md` 生成一份含标题/表格/代码块/任务列表/脚注的样例，方便验收

### 8.3 排版（用户就是要"好看"，这块是重点）
- 正文最大宽 860px 居中，左右留白自适应；正文 16px、行高 1.75、段距 1em
- 中文 Microsoft YaHei UI，代码 Consolas
- 标题明显分层：h1 26px 带底边线、h2 22px、h3 18px，不靠加粗硬区分
- 代码块：圆角 8、浅灰底、内边距 12、横向可滚、右上角语言标签 + "复制"按钮
- 表格：斑马纹 + 单元格边框 + 表头略深底；窄窗口横向滚动不挤压
- 引用块左侧 4px 竖线 + 浅底；任务列表用 ☐/☑；行内 code 浅底小圆角（不要红字）
- 浅色/深色两套 CSS（深色底 `#1E293B`、卡片 `#0F172A`、正文 `#E2E8F0`），工具栏切换并记忆
- 正文字号 Ctrl+加/减 缩放 14~22px
- 所有 CSS/JS 内嵌为程序集资源，**禁止 CDN 或任何远程引用**；代码高亮可以用内嵌的本地 highlight.js 文件，不做也可以（v0.1 允许只是等宽 + 底色）

### 8.4 目录侧栏
- 左侧可折叠，从 h1~h3 生成树；点击平滑滚动定位；滚动时高亮当前章节（IntersectionObserver 或节流 scroll）
- 无标题时显示"本文没有标题"

### 8.5 图片与链接
- 相对路径图片必须能显示（`./img/a.png`、`../b.png` 都要）：用 `SetVirtualHostNameToFolderMapping` 把 md 所在目录映射为虚拟域名
- 图片加载失败显示占位框 + alt 文字
- 点 `.md` 相对链接在本窗口打开目标文件；点 `http(s)` 用默认浏览器打开（走 shell execute，别直接拼命令行）；锚点链接页面内跳转

### 8.6 搜索与导出
- Ctrl+F：WebView2 Find API，输入即搜，显示 `x/y` 命中数，Enter 下一个 / Shift+Enter 上一个 / Esc 关闭并清高亮

- 导出 HTML：内联 CSS 的单文件 html，图片保持相对路径（提示用户一起拷走图片）

### 8.7 文件关联（用户最在意的一步）
