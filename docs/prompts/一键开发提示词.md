## 硬底线（破一条就算没做完）

- **只新增 4 个目录**：`src/TableDiff`、`src/SheetSplitter`、`src/MoneyCalc`、`src/MdViewer`。`src/WorkEnc/` 和 `src/_template/` 一个字节都不许改
- 每个工具三个项目：主 WPF 项目 + `<T>.Core`（net10.0 类库，**不引用 WPF**）+ `<T>.Tests`（xunit）
- .NET 10，`Nullable` 和 `ImplicitUsings` 都 disable
- 数据只写 `%APPDATA%\<exe名>\`，任何持久化写入走 `.tmp` → `File.Replace` → `.bak`
- **工具之间零引用**：B 要用 A 的读表代码，就复制文件过去改命名空间，禁止 `ProjectReference`，也禁止回头改 A
- 界面全中文，不用第三方 UI 控件库，**零网络请求**（唯一例外：MdViewer 里用户主动点"去下载 WebView2"）
- 每个工具独立版本号 `0.1.0`，`settings.json` 带 `Version` 字段

## 执行顺序与阶段门

`A TableDiff → B SheetSplitter → C MoneyCalc → D MdViewer`，**串行，不许并行、不许跳序**（B 要复制 A 的代码，D 最独立所以放最后）。

每个工具必须**过门**才准进下一个：

1. `dotnet build WadeToolbox.slnx -c Release` → 0 警告 0 错误
2. `dotnet test src/<T>/<T>.Tests/<T>.Tests.csproj` → 全通过，用例数达到规格书要求
3. `dotnet publish` 自包含单文件 → exe 能起
4. 规格书该节"验收"清单手动走通（用 `--maketestdata` / `--demo` 造数据，别自己瞎编）
5. 该工具的 `README.md`、`docs/使用说明.md`、`docs/开发记录.md` 写完
