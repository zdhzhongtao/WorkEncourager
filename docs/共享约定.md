# 共享约定

跨越所有工具的统一规矩。写新工具时照着抄，别每做一个换一套风格。

## 界面

### 尺寸与栅格
- 主窗口默认 **宽度 720 ~ 900**，高度自适应内容（WorkEnc 是 700×900 思路）
- 内边距统一 `16`，控件间距 `8` / `12` / `16` 三档，不要出现 5、7、13 这种数
- 圆角统一 `8`，卡片背景用比窗口底色亮/暗 1 档的颜色

### 配色
- 主色：`#2563EB`（蓝），危险/删除：`#DC2626`（红），成功：`#16A34A`（绿）
- 中性色阶：`#F8FAFC` / `#E2E8F0` / `#94A3B8` / `#475569` / `#1E293B`
- **必须支持深色模式**。深色底色 `#1E293B`，卡片 `#0F172A`，正文 `#E2E8F0`
- 金额类数字：涨/正数用红 `#DC2626`，跌/负数用绿 `#16A34A`（中国习惯，别搞反）

### 字体
- 中文 `Microsoft YaHei UI`，数字统一 `Consolas` 或 `Cascadia Mono` 等宽（对齐好看）
- 正文字号 13~14，说明文字 12，标题 16~20，大数字 24~32
- 不要用斜体，不要用小于 11 的字号

### 文案
- 界面文案**全部中文**，不用「OK / Cancel」，用「确定 / 取消」
- 按钮动词开头：「导出报表」而不是「报表导出」
- 报错要说人话：「文件被 Excel 占用了，请先关闭再试」而不是「IOException: sharing violation」

## 数据与文件

| 类型 | 位置 | 格式 |
| --- | --- | --- |
| 配置 | `%APPDATA%\<产品名>\settings.json` | JSON，带 `Version` 字段便于迁移 |
| 历史/业务数据 | `%APPDATA%\<产品名>\history.json` | JSON |
| 日志 | `%APPDATA%\<产品名>\app.log` | 纯文本，按大小轮转（1 MB 上限） |
| 用户导出 | 用户自己选路径 | **CSV 一律 UTF-8 带 BOM**（否则 Excel 打开中文乱码） |

### 写入安全（这条最重要）
任何持久化写入都必须走这个顺序：

1. 写 `xxx.tmp`
2. `File.Replace` 或删除原文件后 rename → `xxx.json`
3. 替换前把旧文件复制成 `xxx.json.bak`
4. 读到损坏文件时：隔离成 `xxx.corrupt-<时间戳>`，回滚 `.bak`，不让程序崩

现成实现见 `src/WorkEnc/WorkEnc.Core/AtomicFile.cs`，可以直接抄。

### CSV 约定
- 编码 UTF-8 **带 BOM**
- 第一行表头，中文列名
- 日期 `yyyy-MM-dd`，时间 `HH:mm`，金额保留 4 位小数
- 不用制表符分隔，不用 `;`

## 代码

- .NET 10，`ImplicitUsings` 和 `Nullable` **关闭**（跟现有工具保持一致，别一半开一半关）
- 纯逻辑抽到 `<工具名>.Core/` 类库，**不引用 WPF**，这样才能单测
- UI 代码可以拆 partial 文件按职责分（WorkEnc 的 `MainWindow.Data.cs` / `.Layout.cs` / `.Settings.cs` / `.Tray.cs` 就是这个思路），单个文件别超 2000 行
- 异步操作用 `async` / `await`，不要在 UI 线程上跑 `File.ReadAllLines` 几十万行
- 不用 `Console.WriteLine` 调试，走 `Log.cs`

## 版本与发版

- 每个工具独立版本号，从 `0.1.0` 起步，`1.0.0` 表示「敢发给同事了」
- 版本号同时改三处：`csproj` 的 `<Version>`、`docs/开发记录.md` 的发版节点、git tag
- tag 格式 `<工具名>-v<版本>`，如 `workenc-v2.2.3`
- 前缀不是装饰：CI 触发和「检查更新」都按它筛。更新检查读 `releases.atom`，
  **不要用 `/releases/latest`**——多工具共用仓库时，它返回的是时间上最新的一次发布，可能是别的工具的
- 发版前必须：全部测试通过 → 自包含发布跑一次 → 截图存 `docs/`

## 隐私

- 不收集任何用户数据，不上报使用统计
- 唯一允许的网络请求：用户主动触发的「检查更新」（拉 GitHub Release 的 version 字段）
- 配置和业务数据里不要出现密码、token；如果确实需要，用 Windows DPAPI 加密（`ProtectedData`）
