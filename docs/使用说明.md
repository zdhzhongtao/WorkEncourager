# 上班鼓励器 · 使用说明

> 本文是给使用者看的完整手册。开发过程与技术踩坑见 [开发记录.md](开发记录.md)。

---

## 一、它是什么

一个常驻 Windows 桌面的半透明悬浮窗，实时算出你上班期间已经赚到多少钱，并把你的实际在岗时长记下来，随时导出成工时报表。

- 单文件 exe，双击即用，不需要安装
- 全部数据只存在你自己的电脑上（`%APPDATA%\WorkEncourager\`），不上传任何服务器

---

## 二、界面速览

窗口有两种形态：**完整界面**（4 个 Tab）和**迷你挂件**（钉在桌面角上的一张小卡片）。

### 完整界面 · 顶部 Tab 条

| Tab | 放什么 |
| --- | --- |
| **主页** | 日常盯的核心数字：今日已赚、鼓励语、暂停按钮、今日工时进度 |
| **明细** | 次要数据：赚钱速度、本月累计、时薪、满勤可得、距发薪天数 |
| **统计** | 历史统计：本周/本月/本年/累计加班四张卡 + 明细 + 导出 |
| **设置** | 所有配置项，改完点「保存」立即生效 |

> 按 `Esc` 可以随时退回「主页」。

### 主页

| 区域 | 含义 |
| --- | --- |
| 标题栏右侧 3 个小图标 | 迷你挂件 / 置顶开关 / 关闭 |
| 日期 + 星期 + 时间 | 实时时钟 |
| 右上角状态胶囊 | `上班中` / `待上班` / `已下班` / `已暂停` |
| 距下班倒计时 | 距收工还剩多久；上班前显示距上班 |
| **今日已赚** | 按秒累加的金额，4 位小数 |
| 鼓励语 | 根据语气与场景自动生成，25 秒轮换一次 |
| 关闭计时器 / 重置 | 暂停计时 / 清零重来 |
| 今日工时进度 | 百分比 + 进度条 + 已工作 X / 总 Y 小时 |

### 明细

当前赚钱速度（元/秒）、本月累计（含进度条）、时薪、今日满勤可得、距发薪 N 天、今日实际在场时长。

### 统计

本周 / 本月 / 本年 / 累计加班四张卡片，明细行，以及「导出工时 CSV」「导出月度汇总」两个按钮。

### 设置

月薪、上下班时间、午休时段、目标物、发薪日、计薪星期多选、透明度、窗体大小、语录语气、深色模式、迷你挂件开关、鼠标穿透、配置导入导出。

### 迷你挂件（桌面小挂件）

点标题栏的**缩略图标**，或设置里的「迷你挂件」开关，窗口就缩成一张 252×112 的小卡片：

```
● 上班中      距下班 06:08:37   [展开]
¥ 87.5508
━━━━━━━━━━━━━━━━━━
```

- 只留最关键的三样：状态、倒计时、今天赚了多少
- **双击卡片**或点「展开」按钮 → 回到完整界面
- 迷你挂件和完整界面**各自记住自己的位置和大小**，互不干扰
- 迷你挂件同样可以拖动位置、缩放大小（小卡片仍然是等比缩放，这样比例不会走形）

## 三、怎么改设置

点顶部的**「设置」Tab**。**设置面板底部有「按当前输入预估」卡片**，你边填边能实时看到日薪/时薪/每秒/满勤的换算结果，确认无误再点「保存」。

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 月薪 | 税前月薪，系统按 21.75 天折算日薪 | 6000 |
| 上班 / 下班时间 | 支持跨天，如 `22:00` → `06:00` 自动识别为第二天 | 09:00 / 18:00 |
| 午休时段 | 可留空；一行一个，如 `12:00-13:00` | 无 |
| 目标物名称 / 单价 | 鼓励语里"再过 X 小时，一件 T恤 就赚回来了" | T恤 / 100 |
| 发薪日 | 1–31 | 10 |
| 计薪星期 | 多选，默认周一到周五 | 周一~周五 |
| 窗体透明度 | 45% ~ 100% 滑块 | 97% |
| 窗体大小 | 小 / 中 / 大 / 重置尺寸（预设尺寸） | 中 |
| 语录语气 | 佛系 / 毒舌 / 热血 | 佛系 |
| 主题 | 浅色 / 深色 | 浅色 |
| 迷你挂件 | 开关。打开后窗口缩成桌面小挂件，点「完整界面」可切回来 | 关 |
| 鼠标穿透 | 开启后**内容区**点击会穿透到下层窗口，顶部标题栏仍可正常点击；再点一次即可关闭 | 关 |
| 幽灵模式 | 鼠标离开窗口时自动变淡（默认 28%），移回来恢复。开会投屏时特别好用 | 关 |
| 边缘吸附 | 迷你挂件拖到屏幕边缘附近会自动贴住，留 6px 缝 | 关 |

> **修改月薪或上下班时间后，所有金额、速度、进度会立即重算**，不需要重启。

## 四、窗口操作

| 操作 | 怎么做 |
| --- | --- |
| 切换页面 | 点顶部 Tab 条：**主页 / 明细 / 统计 / 设置** |
| 回主页 | 按 `Esc` |
| 移动 | 按住面板空白处拖动 |
| **改变大小** | **把鼠标移到窗口最外圈（上下左右边缘或四个角），光标变成双向箭头后拖动** |
| 缩放到预设 | 设置面板 → 窗体大小 → 小 / 中 / 大 / 重置尺寸 |
| 变迷你挂件 | 标题栏的缩略图标，或设置里的「迷你挂件」开关 |
| 迷你挂件变回完整界面 | 双击挂件，或点「展开」 |
| 置顶开关 | 标题栏的图钉图标 |
| 关闭 | 标题栏的 × —— **只是隐藏到托盘，计时继续跑**，不会退出 |

窗口位置和大小会自动记住，下次启动恢复原位。完整界面和迷你挂件**各记各的**位置与大小。

> 边缘缩放用的是自绘的 8 向热区（边条 12px、角落 16px），全部落在窗口最外圈的透明区域里，不会挡住任何内容。
>
> **完整界面不是整体缩放，而是真正的自适应布局**：
> - 拖宽 → Tab 栏、卡片、按钮、进度条都跟着铺开，不会缩在中间留白
> - 拖窄 → 布局自动收窄，文字自动换行，但**字号永远是设定值，不会变小**
> - 高度 → 自动贴合当前页面的内容，**拖不矮到裁切内容**（这一条由程序动态算，跟随页面变化）
> - 宽度下限 320（迷你挂件 200×86），再窄就拖不动了

### 开了鼠标穿透之后怎么退出来

穿透只作用于内容区，**顶部约 50px 的标题栏始终可以点**，所以直接点标题栏那个「鼠标穿透」按钮就能关掉。另外还有三条路，任选：

1. **按 `Ctrl+Alt+X`** —— 全局热键，任何时候都能切换穿透（窗口藏起来了也生效，会顺便把窗口叫出来）
2. **右键托盘图标 → 关闭鼠标穿透**
3. **按住 `Alt` 再点窗口** —— 临时恢复正常交互，可以拖动整个窗口

> 这几个逃生口是 v1.0.2 加的。之前用 `WS_EX_TRANSPARENT` 全窗穿透，连标题栏都点不到，一开就彻底锁死，只能杀进程。

### 托盘（通知区域）

程序常驻系统托盘，**任务栏上不再占位置**。所有操作用托盘图标完成：

| 操作 | 效果 |
| --- | --- |
| 左键单击图标 | 显示 / 隐藏窗口（来回切） |
| 右键 → 显示界面 / 隐藏到托盘 | 同上，文字会跟着当前状态变 |
| 右键 → 切换为迷你挂件 | 直接换形态，不用先显示窗口 |
| 右键 → 暂停计时 / 恢复计时 | 不用把窗口翻出来就能暂停，文案跟着状态变 |
| 右键 → 开启 / 关闭鼠标穿透 | 点不到窗口时的救命入口之一 |
| 右键 → 重置窗口大小与位置 | 窗口被拖得极小或拖到屏幕外时，一键回到默认 432×388 右上角 |
| 右键 → 打开设置 | 显示窗口并跳到设置页 |
| 右键 → 退出 | **真正退出程序**，计时停止 |
| 鼠标悬停 | 显示「状态 · 今日已赚 ¥xx」 |

> Win11 默认把新出现的托盘图标收进 `^` 折叠区。想让它常显，点 `^` 把图标拖到任务栏上即可，系统会记住这个选择。
>
> 窗口隐藏状态下计时、工时记录一切照常，只是不刷界面，CPU 基本归零。

## 五、暂停（关闭计时器）的正确理解

点「关闭计时器」后：

- **会冻结**：今日已赚、赚钱进度、已工作时长、距下班倒计时 —— 数字全部停住
- **会继续走**：右上角的时钟（这是真实时间）
- 状态胶囊变成 `已暂停`，倒计时位置显示「计时已暂停」

再点一次「开启计时器」恢复，**恢复瞬间数字不会跳变**。

暂停期间如果横跨午休，扣减的是"真正落在工作时段内的部分"，午休不会被误扣。

> 暂停状态会写进配置，重启后继续保持在暂停状态。

## 六、怎么算钱

按中国法定 **月计薪天数 21.75 天** 折算（365 − 104 个休息日 = 261 天，÷ 12 = 21.75）：

```
日薪         = 月薪 ÷ 21.75
时薪         = 日薪 ÷ 每日计薪工时（已扣午休）
每秒         = 日薪 ÷ 每日计薪工时秒数
今日已赚     = 每秒 × 今日已工作秒数
今日满勤可得 = 日薪
本月累计     = 本月已过的计薪日 × 日薪 + 今天实际已赚（今天不是计薪日则不加）
```

> 另有「月工作日 20.83 天」（扣除 11 天法定节假日）常被混用，但折算日薪/时薪的标准基数是 **21.75**。

### 休息日

周末和法定假日打开程序，状态胶囊显示 `休息日`，倒计时位置写「今天休息 · 加班工时照常记录」：

- 今日已赚照常按实际时长计算（周末加班该给的钱还是给）
- 但**不会并入「本月累计」**，那个数字只按计薪日推进，避免月薪进度虚高一天
- 工时仍然记进 CSV 报表，周末干的活不会白干

### 节假日与调休

内置 **2026 年**法定假日与调休上班日（依据《国务院办公厅关于 2026 年部分节假日安排的通知》国办发明电〔2025〕7 号）。「本月累计」会自动扣除假日、补上调休上班日。

内置表只到 2026 年。**从 2027 年起需要在设置里补「自定义放假日 / 自定义调休上班日」**（格式 `2027-01-01`，多个用逗号分隔）。当年份没有内置数据时，设置页会显示一条琥珀色提示，提醒你补齐；不补的话，元旦、国庆这类固定假日会被当成工作日算进月累计。

### 午休不计薪

`09:00-18:00` + 午休 `12:00-13:00` → 实际计薪工时 8 小时，时薪和每秒都按 8 小时算。

支持多段午休：填 `12:00-13:00, 18:00-18:30`，两段都会被扣掉。

## 七、"开着就在工作"与工时报表

程序运行且处于上班时段内，即视为在岗。实际在场时长：

- **跨重启累计**（关机期间不追补，关多久都不算）
- **睡眠 / 休眠期间不追补**（程序每 200ms 跳一次，一旦超过 90 秒没跳就判定机器睡过，只记最后 90 秒，合盖 3 小时不会被算成加班 3 小时）
- **跨天按自然日切分归属**，不会把凌晨的工时记到前一天
- **暂停期间不计入**
- **超出下班时间的部分单独计为加班**

导出 CSV：**统计 Tab** →「导出工时 CSV」或「导出月度汇总」。

导出后提示框里的**路径可以直接选中复制**（也可以点「复制路径」按钮复制到剪贴板，或点「打开文件夹」直接在资源管理器里定位）。

文件保存在 `%APPDATA%\WorkEncourager\`，UTF-8 BOM 编码，Excel 双击直接打开不乱码。

### 工时报表格式（按天一行）

```
日期,星期,是否计薪日,备注,首次上班,最后下班,实际工时(小时),应出勤(小时),加班(小时),当日已赚(元)
2026-11-04,周三,是,,09:02,17:05,8.00,9.00,0.00,88.8889
```

| 列 | 含义 |
| --- | --- |
| 日期 | `yyyy-MM-dd` |
| 星期 | 周一 ~ 周日 |
| 是否计薪日 | 是 / 否（按你在设置里勾的计薪星期 + 节假日日历判定） |
| 备注 | 法定节假日 / 调休上班，空表示正常上班 |
| 首次上班 | 当天第一次被记录到在场的时刻 |
| 最后下班 | 当天最后一次被记录到在场的时刻 |
| 实际工时 | 程序实际记录到的在岗小时数 |
| 应出勤 | 按作息表算的应出勤小时数（已扣午休） |
| 加班 | 超出下班时间的部分 |
| 当日已赚 | 当天累计赚到的金额 |

### 月度汇总格式（按月一行）

```
月份,计薪日数,出勤日数,实际工时(小时),加班(小时),本月已赚(元),日均工时(小时)
2026-11,21,5,37.70,0.50,354.4570,7.54
```

> 出勤日 = 当天实际工时 > 1 分钟。

## 九、工时导入、备份与语录

### 导入外部工时

设置页 → 数据导出与导入 → **导入工时数据…**，选一个 CSV / TXT 文件。

- 打开对话框时会**直接定位到上次导入的目录**，不用每次翻文件夹
- 语义是**按日期增量合并**：文件里有的日期就更新，没有的日期一条不动；同一天导入两遍结果完全一样，可以放心重复点
- 导入的工时按**当前月薪**重算金额，和程序自己算的口径一致

文件格式（UTF-8，第一行表头可有可无）：

```
日期,首次上班,最后下班,实际工时(小时),加班(小时),备注
2026-11-05,09:02,18:30,8.50,0.50,正常
```

最少只要两列 `日期,工时` 也能导：

```
2026-11-05,8.5
2026-11-06,7.25
```

解析器比较宽容，下面这些都能认：

| 情况 | 处理 |
| --- | --- |
| 表头写中文或英文 | `日期/date`、`上班/in`、`工时/hours`、`加班/overtime`、`备注/note` 都认 |
| 没有表头 | 按第一行数据猜列：2 列当「日期,工时」，3 列且后两列是时间当「日期,上班,下班」 |
| 只给了上下班时间 | 自动算工时，跨天夜班 `22:00→06:00` 算对 8 小时 |
| 工时写成 `8:30` | 当 8.5 小时 |
| 日期写成 `2026/11/5`、`20261105`、`11-05` | 都认，`11-05` 按今年补全 |
| 备注里带逗号 | 用双引号包起来就行 |

解析不了的行会在提示里告诉你第几行、为什么，不影响其它行导入。

### 备份与恢复

设置页 → **备份全部数据**：把 `settings.json`、`history.json`、`quotes.csv` 打成一个 zip，默认存到桌面。

**从备份恢复**：先把你现在的三个文件原样复制到 `before-restore-时间戳` 文件夹，再解压覆盖。恢复错了随时能拿回去。

### 编辑语录

设置页 → **编辑语录…**，会用系统默认程序打开：

```
%APPDATA%\WorkEncourager\quotes.csv
```

三列结构，Excel / WPS 直接编辑：

```
语气,情境,语录
佛系,首件,再过 {TIME}，一件{ITEM}就赚回来了
毒舌,多件,{COUNT} 件{ITEM}到手，剩下 {TIME}，你确定不多赚点？
```

- 语气：`佛系` / `毒舌` / `热血`（也认 `chill` / `savage` / `hype`）
- 情境：`首件` / `多件` / `买不够`
- 占位符：`{ITEM}` 目标物、`{TIME}` 时长、`{EARNED}` 已赚、`{COUNT}` 件数、`{CANBUY}` 还能买几件
- 只改某一组也可以，没写的组继续用内置语录
- **保存后 5 秒内自动生效**，不用重启。保存时请选「CSV UTF-8」，否则中文会乱码

## 十、常见问题

**Q：为什么"今日已赚"和"今日实际在场"对不上？**
A：两个数刻意不同。「今日已赚」是按当前时钟从上班时间算到现在的**应得**金额；「今日实际在场」是程序**真实记录到**你在场的累计时长（只统计程序开着的时间）。后者才是工时报表的依据。

**Q：换了新电脑怎么把数据带过去？**
A：把 `%APPDATA%\WorkEncourager\` 整个目录拷过去。里面有 `settings.json`（设置）、`history.json`（工时历史）和导出的 CSV。

**Q：鼠标穿透开了以后点不到窗口、也关不掉？**
A：v1.0.2 已修。现在穿透只作用于内容区，标题栏照样能点；还可以按 `Ctrl+Alt+X`、或右键托盘图标关闭穿透。如果窗口位置不对，按住 `Alt` 就能拖动。

**Q：透明度调低文字也变淡了？**
A：WPF 的窗口级透明度就是这样，整窗一起淡。想让文字保持清晰，可以只用深色主题，或切到迷你挂件（字更少更粗）。

**Q：程序需要一直开着吗？**
A：是的。"开着就在工作"就是这么设计的 —— 关掉程序的时间不计入工时。不过不用把它摆在桌面上：点 × 收进托盘就行，计时不会停。

**Q：窗口不见了，怎么找回来？**
A：它藏到托盘里了。左键单击通知区域的「上班鼓励器」图标即可；图标可能被 Win11 收在 `^` 折叠区里。

**Q：怎么才算真正退出？**
A：标题栏的 × 只隐藏窗口。要退出必须走**托盘右键 → 退出**，或者在注销 / 关机时系统会正常关掉它（数据会保存）。

**Q：不小心开了两个会怎样？**
A：不会。第二次双击图标会直接激活已经在跑的那个窗口，然后自己退出，不会出现两份数据互相覆盖。

**Q：数据文件万一损坏了？**
A：程序每次写入都走「临时文件 + 原子替换」，并把上一版留成 `.bak`。读到坏文件时会自动隔离成 `xxx.corrupt-时间戳` 并从 `.bak` 恢复，不会静默清空你的历史。
